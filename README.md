# Bioinformatics Project

A collection of bioinformatics and computational biology projects focused on biological data analysis, genomics, transcriptomics, and machine learning.

## Projects

### 1. Transcriptomics Analysis

End-to-end RNA-seq transcriptomics analysis workflow, covering:

- Raw RNA-seq data download
- Sequence quality control using FastQC and MultiQC
- Read trimming and quality filtering
- Read alignment
- Gene/transcript quantification
- Differential gene expression analysis
- Gene set and pathway enrichment analysis

**Tools & Technologies:**  
Python, R, Bash, FastQC, MultiQC, STAR, HISAT2, featureCounts, DESeq2, GSVA, GSEA, Snakemake

📁 **Project:** [`Transcriptomics_analysis`](./Transcriptomics_analysis/)
